# 🛒 Grocery Shopping App

A modern grocery shopping app built with **Flutter**. Supports **Android, iOS, Web, Windows, macOS, and Linux**. Features a **shopping cart, state management with Provider, and a clean UI**.

## 📌 Features
✅ Browse and select grocery items  
✅ Add items to the shopping cart  
✅ Remove items from the cart  
✅ View total price dynamically  
✅ Multi-platform support (Android, iOS, Web, Desktop)

## 🚀 Installation & Setup
### **1️⃣ Clone the Repository**
```sh
git clone https://github.com/asharsyedali/groceryapp.git
cd groceryapp
```

### **2️⃣ Install Dependencies**
```sh
flutter pub get
```

### **3️⃣ Run the App**
- **Android/iOS:**
```sh
flutter run
```
- **Web:**
```sh
flutter run -d chrome
```
- **Windows/Linux/macOS:**
```sh
flutter run -d windows  # or linux/macos
```
